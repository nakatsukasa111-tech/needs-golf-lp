# NeeDS 40〜50代女性向けLP（`women40/`）

プライベートジムNeeDS（株式会社NeeDS）の、**40〜50代女性向け**集客ランディングページ。
`needs-golf-lp` の `index.html` をベースに、ターゲットと訴求を差し替えたものです。

## 訴求の軸

**「機能的な体は、美しい。」／「体重計の数字より、鏡に映る姿勢を。」**

体重を落とすことではなく、機能的な体づくり（美しさ・機能性・健康）を打ち出す。
**肩甲骨／股関節／体幹／インナーマッスル／バランス**の5つを冒頭から提示し、全体を通して訴求する。

- ターゲット：40〜50代の女性
- 拾う悩み：体の痛み・違和感／疲れ・疲労感／姿勢の崩れ／たるみ・体の衰え／食事を減らしても戻らない
- 安心材料：指導実績15年以上／リピート率90%以上／平均継続年数3年以上／1対1・優しいトレーナー
- CTA：公式LINE登録 → 無料体験予約（ページ内5箇所＋スマホ用の画面下部固定バー）
- ブランドカラー：`#0d669b` ／ CTAはオレンジ `#ee8340`→`#cf611c`（ゴルフLPと共通）
- 計測：GTM `GTM-P95C26ZR`。CTAクリック時に `cta_click` を送信
  （`cta_position` は `header` / `hero` / `trainer` / `trial` / `footer` / `sticky`）

## セクション構成

ヘッダー／ファーストビュー／お悩み（5項目）／コンセプト（5つの軸＋写真3点）／
実績（数字4つ）／トレーナー3名／無料体験／FAQ（5問）／店舗／フッター

文字量を抑え、写真を大きく見せる構成にしています。

主要なコピー：

- ファーストビュー「機能的な体は、美しい。」＋「だからこそNeeDSは、スポーツ由来のトレーニングメソッドです。」
- お悩みの締め「心当たりがあるなら、いまが、始めどきです。」
- コンセプト「体重計の数字より、鏡に映る姿勢を。」＋朝の体の軽さ・鏡の立ち姿・
  「体が戻ってきた」「自分の体で良かった」という感覚を訴求
- 5つの軸（肩甲骨／股関節／体幹／インナーマッスル／バランス）を縦並びにし、
  それぞれ1〜2文の解説を添える
- 締め「美しさと、機能性と、健康を。その3つは、同じ方向にあります。」
- 実績「プロアスリートやドクターにも選ばれている方法を、あなたに。」
- トレーナー「はじめての方こそ、安心して。」＋「だからNeeDSは、10年以上選ばれ続けています。」
- 無料体験「まずは、無料体験でお試しください。」＋「無理な勧誘はいたしません／ご相談のみでも大丈夫です」）

## 確認済みの動作

390px / 768px / 1440px でレンダリングして確認済み。

- 横スクロールなし（`scrollWidth === clientWidth`）
- 画像12点すべて読み込み成功（`naturalWidth > 0`）
- JSエラーなし／リクエスト失敗なし
- CTAボタンの文言はすべて1行に収まる
- 日本語の行末に1〜2文字だけ残る箇所なし（360 / 390 / 768 / 1440px）
- FAQ開閉、画面下部固定バーの表示制御、`cta_click` 送信（6箇所すべて）
- `prefers-reduced-motion: reduce` でフェードインを無効化

## 表記上の配慮

- 薬機法：医療的・生理的な効果は断定していない。たるみ・衰えは「お悩み」として提示し、
  効果としては「姿勢」「動き」「支える力」の範囲に留めている
- 更年期のFAQに「トレーニングは治療ではない」旨と医療機関の受診案内を明記
- 実績の数値には「※ 数値は当社実績です。感じ方・変化には個人差があります」を併記
- 「他とは全く違う」といった比較優良表現は使わず、指導実績という事実で示している
- 「プロアスリートやドクターも認めた」ではなく「選ばれている」とし、
  推奨・認定の主張ではなく、実際にご利用いただいているという事実の表現にしている
- 「基礎代謝が上がる」と断定せず「基礎代謝の土台も整っていきます」としている（薬機法）
- 「申し込む」という文言は不使用
