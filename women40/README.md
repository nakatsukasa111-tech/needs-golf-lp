# NeeDS 40〜50代女性向けLP（`women40/`）

プライベートジムNeeDS（株式会社NeeDS）の、**40〜50代女性向け**集客ランディングページ。
`needs-golf-lp` の `index.html` をベースに、ターゲットと訴求を差し替えたものです。

## ファイル

| パス | 内容 |
|---|---|
| `index.html` | LP本体。CSS・JSを内包した単体HTML。外部依存はGoogle FontsとGTMのみ |
| `images/` | 写真・ロゴ。現在は写真がすべて仮画像（プレースホルダー） |

## コンセプト

「体重計の数字より、鏡に映る姿勢を。」

減量ではなく**コンディショニング（姿勢と動きを整える）**を軸にする。
胸まわり・肩甲骨／股関節／体幹の3つを、体の変化ではなく**生活での実感**として訴求する。

- ターゲット：40〜50代の女性。健康を意識し、「美しく、健康でいたい」と考えている層
- CTA：公式LINE登録 → 無料体験予約（ページ内5箇所＋スマホ用の画面下部固定バー）
- ブランドカラー：`#0d669b` ／ CTAはオレンジ `#ee8340`→`#cf611c`（ゴルフLPと共通）
- 計測：Google Tag Manager `GTM-P95C26ZR`。CTAクリック時に `cta_click` イベントを送信
  （`cta_position` の値は `header` / `hero` / `method` / `trial` / `footer` / `sticky`）

## 確認済みの動作

390px / 768px / 1440px でレンダリングして確認済み。

- 横スクロールなし（`scrollWidth === clientWidth`）
- 画像13点すべて読み込み成功（`naturalWidth > 0`）
- JSエラーなし／リクエスト失敗なし
- CTAボタンの文言はすべて1行に収まる
- 日本語の行末に1〜2文字だけ残る箇所なし（360px / 390px / 768px / 1440px）
- FAQ開閉、画面下部固定バーの表示制御、`cta_click` イベント送信（6箇所すべて）
- `prefers-reduced-motion: reduce` でフェードインを無効化

## 表記上の配慮

- 薬機法：医療的・生理的な効果は断定していない（「〜と感じる方が多い」等の書き方に統一）
